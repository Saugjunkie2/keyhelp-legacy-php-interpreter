# Bauanleitungen des Ergänzungssatzes

Die Skripte unter `bibliotheken/` und `zusammenbau/` sind unverändert die Fassungen, mit denen der Ergänzungssatz 1.1.0 entstand. Sie laufen als root in einer Debian-13-Chroot mit diesem Repository unter `/khli/baum`; Ablauf: [docs/bau.md](../docs/bau.md). Ihre Kommentare verweisen auf die interne Projektdokumentation (Kürzel wie `E-0040` oder `docs/45`), die nicht veröffentlicht ist; „PROD" steht dort für den Debian-12-Referenzserver.

The scripts in `bibliotheken/` and `zusammenbau/` are unchanged the versions with which supplement 1.1.0 was built. They run as root in a Debian 13 chroot with this repository at `/khli/baum`; steps: [docs/en/building.md](../docs/en/building.md). Their comments refer to the unpublished internal project documentation; "PROD" there stands for the Debian 12 reference server.
